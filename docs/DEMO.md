# 데모 GIF 만들기

README 맨 위에 들어갈 `docs/demo.gif` 를 만드는 절차.
**보여줄 장면은 하나다 — 시간이 겹쳐서 개설이 막히는 순간.**

기능을 이것저것 훑는 영상은 아무 인상도 남기지 않는다.
"막힌다"는 장면 하나가 이 프로젝트의 주제를 그대로 보여준다.

---

## 1. 도구

**[ScreenToGif](https://www.screentogif.com)** — 무료, 설치형, 녹화하면 바로 GIF가 나온다.
편집기가 내장돼 있어 앞뒤 자르기와 속도 조절을 그 안에서 끝낼 수 있다.

> Windows 기본 캡처 도구는 mp4만 나와서 변환을 한 번 더 거쳐야 한다.

---

## 2. 준비

```bash
npm run seed         # 샘플 강좌를 원래대로
npm run dev          # 터미널 1
npm run dev:client   # 터미널 2
```

1. 브라우저에서 http://localhost:5173 → `admin@eduflow.test` / `eduflow123!` 로 로그인
2. **브라우저 창을 1000×700 정도로 줄인다.** 전체 화면으로 찍으면 글씨가 뭉개진다
3. 개발자 도구, 북마크바, 알림 같은 건 다 닫는다
4. 시간표에 `중등 수학 A반`(김수학 / 화·목 19:00~20:30)이 보이는 주로 이동

---

## 3. 녹화할 순서

15초면 충분하다. 마우스를 천천히 움직인다.

| | 동작 | 보여지는 것 |
|---|---|---|
| 1 | 시간표를 1초쯤 그대로 둔다 | 화요일 19시에 이미 수업이 있음 |
| 2 | 좌측 폼: 강좌명 `중등 수학 B반` | |
| 3 | 강사 **김수학**, 강의실 아무거나 | ← 이미 그 시간에 수업이 있는 강사 |
| 4 | 요일 **화**, 시각 **19:00~20:30** | 기존 수업과 정확히 겹치게 |
| 5 | **개설하기** 클릭 | |
| 6 | **빨간 경고가 뜬다** — 2초쯤 멈춘다 | ★ 이 장면이 핵심 |
| 7 | 시작 시각만 **21:00~22:30** 으로 변경 | |
| 8 | **개설하기** 클릭 | |
| 9 | 초록 성공 메시지 + 시간표에 새 블록 | 조건만 맞으면 정상 개설됨 |

6번에서 반드시 **2초 이상 멈춘다.** GIF는 소리가 없어서
읽을 시간을 주지 않으면 무슨 일이 일어났는지 전달되지 않는다.

---

## 4. 저장

ScreenToGif 편집기에서:

- 앞뒤의 빈 프레임 잘라내기
- **초당 프레임 15** 정도 (부드럽지만 용량이 크지 않다)
- 크기 **가로 900px 이하**로 줄이기
- 파일 → 다른 이름으로 저장 → **`D:\project\docs\demo.gif`**

**5MB 이하**를 목표로 한다. 넘으면 프레임을 솎아내거나 크기를 더 줄인다.
GitHub에서 큰 GIF는 로딩이 느려서 스크롤로 지나가버린다.

---

## 5. 확인

```bash
git add docs/demo.gif
git commit -m "docs: 데모 GIF 추가"
git push
```

GitHub 레포 첫 화면에서 **GIF가 자동 재생되는지** 본다.
README의 이미지 경로는 이미 `docs/demo.gif` 로 잡혀 있다.
