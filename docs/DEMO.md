# 데모 스크린샷 만들기

README 맨 위에 들어갈 `docs/demo-conflict.png` 를 만드는 절차. 설치할 것은 없다.

**담을 장면은 하나다 — 시간이 겹쳐서 개설이 막히는 순간.**
기능을 훑는 영상은 인상을 남기지 않는다. "막힌다"는 화면 한 장이 이 프로젝트의 주제다.

---

## 1. 준비

서버 두 개를 띄우고 http://localhost:5173 에서 `admin@eduflow.test` / `eduflow123!` 로 로그인.

브라우저 창을 **너무 크게 두지 않는다.** 전체화면으로 찍으면 GitHub에서 글씨가 뭉개진다.
개발자 도구와 북마크바는 닫는다.

시드 상태에서 **김수학** 강사는 이미 이 수업들을 맡고 있다.

| 강좌 | 강의실 | 요일·시각 |
|---|---|---|
| 중등 수학 A반 | 201호 | 화·목 19:00~20:30 |
| 중등 수학 심화 | 301호 | 금 19:00~21:00 |

---

## 2. 충돌 일으키기

좌측 **강좌 개설** 폼에 이렇게 넣는다.

| 항목 | 값 |
|---|---|
| 강좌명 | `중등 수학 B반` |
| 강사 | **김수학** ← 이미 그 시간에 수업이 있는 강사 |
| 강의실 | 아무거나 |
| 요일 | **화** |
| 시작 / 종료 | **19:00 / 20:30** ← 기존 수업과 정확히 겹치게 |

**개설하기** 클릭 → **빨간 경고**가 뜬다.

> `강사 김수학의 일정이 겹칩니다. (중등 수학 A반)`

---

## 3. 캡처

**`Win` + `Shift` + `S`** → 영역 선택 → **왼쪽 폼과 빨간 경고가 함께** 들어가게 드래그.

오른쪽 시간표까지 같이 들어가면 더 좋다.
"화요일 19시가 이미 차 있다"는 근거가 한 화면에 보이기 때문이다.

캡처하면 우측 하단에 알림이 뜬다. 그걸 눌러 **캡처 도구**가 열리면
`Ctrl + S` → 아래 경로로 저장한다.

```
D:\project\docs\demo-conflict.png
```

> 알림을 놓쳤으면 이미 클립보드에 있다. 그림판을 열고 `Ctrl + V` → 같은 경로로 저장.

---

## 4. 커밋하고 올리기

```bash
git add docs/demo-conflict.png
git commit -m "docs: 데모 스크린샷 추가"
git push
```

GitHub 첫 화면에서 이미지가 보이는지 확인한다.
README의 경로는 이미 `docs/demo-conflict.png` 로 잡혀 있다.
